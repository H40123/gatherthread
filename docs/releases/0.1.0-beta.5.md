# GatherThread 0.1.0-beta.5 — Beta 5

Beta 5 repairs native Codex synchronization, Launcher connection status and the
Agent sharing list. It includes the reviewed main-branch account/conversation
controls and compact Agent management entry from after the Beta 4 release.
Publication records and deployment receipts establish availability; these notes
alone do not.

## Fixes

- Codex Desktop's automatically generated next-message suggestions no longer
  create cloud Solo conversations or upload as human turns. The same recognized
  envelope is excluded from live Hooks, old offline spools and completed local
  history recovery. Real human prompts and per-conversation upload choices keep
  their existing behavior.
- The macOS Launcher displays short connector log lines immediately. Both
  Launchers change to connected after project/session readiness, including an
  empty project. Replaced child processes cannot overwrite the current status;
  the active child's final error logs remain visible after exit.
- Unconfigured sharing runtimes belonging to the same device and Agent appear
  as one connection. Separate same-name devices remain distinguishable. Saved
  sharing grants and Stop controls keep their exact source, while refresh
  preserves the source being edited and keyboard focus.

Previously captured suggestion drafts that were never submitted are discarded
before publishing. An older `commit_unknown` record retains its exact private
evidence and uncertainty barrier; it is not retried or falsely acknowledged.
This repair does not delete existing cloud messages, native tasks, devices or
sharing grants. Any uncertain historical write needs a separately verified
resolution rather than an invented success receipt.

independent test/production accounts, databases, secrets, test admission and
configuration. Take verified backups before startup migrations and bind the
effective static directory to the new release. Never roll back databases after

its immutable image ID and original source provenance; do not relabel that image
