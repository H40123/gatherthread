# GatherThread 0.1.0-beta.2 — Beta 2

Beta 2 gathers the reviewed changes since Beta 1 into the current application,
Codex connector, DeepSeek Harness plugin and Launcher downloads. It keeps the
same product focus: discuss and develop together, then continue on another device.
Beta 1 packages, tags and historical installation files are not overwritten.

## Highlights

- Live answers, native-exposed thinking summaries, tools and plans appear in the
  shared work page, with separate collapsible sections. Codex hidden reasoning and
  unrelated local conversations remain excluded.
- Cloud Agent requests have working Pause/Resume, exact-profile Retry and explicit
  continuation after a timeout. Shared summaries can use the selected cloud model;
  a local Agent is not required for configuring the workspace.
- GitHub setup follows a short account → repository → file-use flow, with separate
  owner/name inputs and an official repository-creation link. GitHub is recommended
  for ongoing development; GT Cloud remains a bounded small-project alternative.
- The compact desktop/mobile composer keeps sending actions visible. Registration
  and recovery forms remain scrollable and accept 8–128 password characters.
- The Launcher fills the current email/environment and exchanges a private device
  credential after password sign-in. New downloads bundle the Beta 2 connector and
  plugin; the macOS app's required numeric version is 0.1.2.
- The reviewed DSH runtime pin is `@deepseek-ai/dsh@0.1.7-rc.2`. Withdrawn model
  routes require an explicit new selection, and model dropdowns remain readable
  under a dark harness theme.
- The beginner example now contains a six-file signup page, source inspection,
  three real behavior checks, a working button and teammate review. The bilingual
  product guides and annotated computer/phone/tablet images follow that workflow.

The [changelog](../../CHANGELOG.md) contains the technical changes; current user
instructions live in the [product guide](../PRODUCT_GUIDE.md) and
[中文图文指南](../PRODUCT_GUIDE.zh-CN.md).

## Matching packages and source

- npm: `@gatherthread/codex-connect@0.1.0-beta.2` and
  `@gatherthread/dsh-host@0.1.0-beta.2`.
- Source tag: `v0.1.0-beta.2`. Publication records provide the full source commit,
  package integrity and download checksums; a version label alone is not a build proof.
- Launcher assets come from that same source, with their own platform provenance.
  macOS remains ad-hoc signed, not Developer ID signed or notarized.

Prefer **Connect Codex → Open Launcher**, or the source-matched download index.
The [Codex guide](../CODEX_CONNECT.md) and [DSH guide](../DSH_CONNECT.md) retain the
advanced terminal/source paths. The release marketplace identity is:

```bash
codex plugin marketplace add https://github.com/TH060419/gatherthread.git --ref v0.1.0-beta.2 --sparse .agents/plugins --sparse plugins/gatherthread
codex plugin add gatherthread@gatherthread
```

That identity is not a substitute for preparing the source plugin: the source
launcher fails closed when its bundled connector is missing. Follow the Launcher
flow or the source guide's `prepare-source-plugin.mjs` and prepared-directory
installation steps before enabling Hooks. Do not put passwords or device codes
in copied commands.

## Rollout and verification

The rollout first targets `test.gatherthread.cn`. Promotion to `gatherthread.cn`
requires the user's later instruction and reuses the same build, not a rebuild
or another full test campaign. Test accounts, databases and secrets are never
copied into production; production's own settings and account data remain separate.

Existing feature review and successful CI are reused. This metadata release adds
only version/package consistency and necessary build/download checks; it does not
repeat live-model, browser or container diagnostics on the server. Deployment
receipts, rather than this document, confirm which service is actually running.

Cloud model/provider configuration and the current shared-host resource policy
are preserved. Reusing an unchanged hosted image retains its original digest and
source provenance; it is not relabelled as newly tested Beta 2 code.
